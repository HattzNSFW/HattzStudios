# Infrastructure Adapters (Fase 2A)

Preparação de contratos/adapters de infraestrutura **sem conexões externas**.

- Interfaces de leitura pública (Share) devem consumir apenas dados publicados.
- Adapters de publicação/sincronização/armazenamento/auditoria serão concretizados em fases autorizadas com configuração segura.
- Nenhum adapter desta fase conecta Supabase, serviços externos ou credenciais.
